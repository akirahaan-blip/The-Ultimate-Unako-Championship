# The Ultimate Unako Championship スコアチェッカー

ポケモンスリープの独自イベント「The Ultimate Unako Championship（うなこ杯）」用スコア判定Webアプリケーションです。

## 🌟 特徴
- **📸 スクショ自動認識**: ポケモンのステータス画面（スクリーンショット）をアップロードするだけで、SP・性格・食材・サブスキル等を自動抽出！
- **🧮 正確な自動スコアリング**: Lv70(1割引)・Lv80(3割引)やコンボボーナス（3種の神器、こてい個体、オール金）、SPゾロ目・キリ番などを完全網羅。
- **📱 スクショ最適化デザイン**: スマホ画面1枚で綺麗にスクショが撮れる洗練された結果カードレイアウト。
- **📝 完全選択式・タップ操作**: 手動での微調整もドロップダウンやチェックボックスで片手でサクサク入力可能。
- **💾 履歴保存**: 端末内（localStorage）に個体のスコア履歴を保存・管理。
